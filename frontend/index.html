Tentang Arsitektur GISHUB

GISHUB (Simpul Transportasi) adalah platform geospasial resmi milik Kementerian Perhubungan RI berbasis GeoNode & GeoServer OGC Standard.

Aplikasi WebGIS ini terhubung secara langsung menggunakan:

  • OGC WMS: Rendering cepat jutaan garis alur dan poligon via server GISHUB Kemenhub.
  • OGC WFS & GeoJSON: Mengambil geometri fitur dan data tabular secara dinamis.
  • PostGIS 3.6: Mesin analisis spasial backend untuk query geodetik dan relasi spasial.
